10. Methodology

Expected goals derive from each team's last-{{ form_n }} scoring and concession rates normalised against the sample baseline, projected through independent Poisson distributions into a full scoreline matrix. Count markets project combined expected totals through the same Poisson framework. Verified context factors from current reporting are applied as bounded multiplicative adjustments (net cap ±20% per market) and every adjustment is traceable to its source. Where context contradicts the raw model the conflict is flagged, never hidden. The keccak-256 hash of this document and its canonical forecast set is committed to the X Layer testnet blockchain before kickoff, and every forecast is publicly graded after full time.
